# 시안 stage — 무대

CSS: `src/app/directions/stage.css` · 화면: `shots/` (48장, `index.md`) · 2026-11-04

## 1. 한 줄

LEO 를 **"소리 내 연습하는 밝은 무대"** 로 보이게 한다. 크림 캔버스 위에 코랄 하나를 면(面)으로 크게 쓰고, 활자는 Pretendard 800~900 으로 굵고 크게, 모든 조작은 알약이다. 통화 화면만은 라이트·다크 모두 어두운 무대다.

## 2. 왜 이 서비스에 맞는가 (00-understanding 4절의 다섯 가지)

1. **장소**: 첫 화면에서 코랄 블록(통화 시작하기)과 복숭아 블록(채팅 시작)이 화면 절반을 차지한다. 흰 카드 + 파란 버튼의 SaaS 문법이 사라지고 "들어가서 말하는 곳" 이 된다.
2. **영어가 주인공**: 대화는 18px·500 의 큰 알약 말풍선, 내 말은 코랄 면 위 흰 글자. 한국어 UI 는 15~16px·700 로 작고 단단하게 뒤로 물러난다. 서체는 하나(Pretendard)지만 크기·굵기·면으로 목소리를 가른다.
3. **통화는 통화답게**: 어두운 무대 위에 72px·900 시계, 72px 높이의 상태 알약(듣는 중 초록 / 말하는 중 코랄 / 음소거 빨강), 64px 알약 컨트롤. 전사는 그 아래로 물러난다.
4. **리포트는 코치의 메모답게**: 점수는 등급색 타일 위 56px 숫자("6/10")와 12px 알약 막대, 교정은 초록 6px 왼쪽 막대와 20px·800 교정문, 다음 행동은 56px 코랄 알약 하나. 표가 아니라 "크게 적어 준 메모" 로 읽힌다.
5. **라이트·다크 각각**: 라이트는 크림 위 진한 코랄(#d1370f), 다크는 따뜻한 검정 위 밝은 코랄(#ff7a5c)이고 1차 버튼 글자는 다크에서 어두운 갈색(#2b0d05)이다. 반전이 아니라 "낮 무대 / 밤 무대" 다.

## 3. 어떤 사용자 이해에서 나왔는가

사용자는 시험 앞에 선 성인 개발자다(00-understanding 2절). 이 시안은 긴장을 **빼지 않고 밀어낸다**: Speak 가 말하기를 "부담 없는 반복", 업beat 한 톤으로 프레이밍하듯(01-exploration 1절), 큰 글자·큰 버튼·한 가지 색으로 "지금 할 일 하나" 만 보이게 해서 망설일 틈을 줄인다. 실수를 보여 주는 리포트는 Cambly 의 "판단 없는 자리" 처럼 점수 타일이 평가표가 아니라 응원 카드로 읽히게 숫자를 크게, 등급 배지를 흰 알약으로 둔다. 마스코트·이모지·둥근 그림은 쓰지 않는다 — 어른의 기세여야지 어린이 앱이면 안 된다.

코랄 하나를 글자(링크·제안 표현)와 면(버튼·블록)에 같이 쓰려면 라이트 값이 크림 위 4.5:1 과 흰 글자 4.5:1 을 동시에 넘어야 해서 #d63a18 보다 어두운 **#d1370f** 로 정했다(4.59:1 / 4.92:1). 파랑은 어디에도 없다. 그림자는 전부 `none`.

**서체**: Pretendard Variable 그대로. 본문 500, h1 36px·900·-0.03em, 카드 제목 22px·800, 홈 블록 제목 32px·900, 로그인 브랜드 96px·900·-0.04em, 통화 시계 72px·900·-0.05em(tabular), 점수 56px·900, 교정문 20px·800, 영어 말풍선 18px·500·1.5, 버튼 15px·800.

**형태**: 버튼·메뉴·선택지·상태·필터·목차 전부 알약(999px). 카드 24px 라운드 + 2px 테두리(divider 색). 입력창 52px 알약 2px 테두리, 채팅 입력은 잉크 2px. 말풍선 28px 라운드에 위 안쪽 모서리만 8px(꼬리 대신). 점수 막대 12px 알약, 교정 왼쪽 막대 6px.

**밀도**: 현행보다 한 단계 성기다(카드 패딩 24, 목록 항목 20/24, 헤더 72px, 터치 타깃 48px 기본·통화 64px).

**대화**: 내 말 = 코랄 면, 상대 = 흰(다크: #2a2521) 면 + 2px 테두리. 힌트 = 초록 작은 알약(15px·700). 입력 중(interim)은 2px 점선 코랄.

**통화**: `.call-shell` 안에서 색 토큰 31개를 다크 값으로 다시 선언해 라이트에서도 어두운 무대가 된다. 이유: (1) 10분 동안 보는 화면이라 눈부심이 없어야 하고, (2) 상태 색(초록·코랄·빨강)이 검정 위에서 가장 멀리 보이며, (3) "조명이 꺼지고 무대만 밝은" 전환이 통화 시작을 분명한 사건으로 만든다. 시계는 캔버스 폭에 맞춰 `clamp(4rem, 18vw, 4.5rem)` 이라 390px 에서도 64px 이상이다. 1분 남으면 시계·링이 황색.

**리포트**: 점수 타일은 등급에 따라 면색이 바뀐다(high 초록, mid 코랄, low 황토) 와 그 위 글자는 각각의 `on-*`. 등급 배지는 면·글자를 뒤집은 흰 알약이라 12px 글자도 4.5:1 이상이다.

## 6. 이 방향을 택하면 포기하는 것

- **조용함.** 홈·리포트·통화 모두 코랄 면이 크다. 하루 여러 번 열면 피로할 수 있다.
- **섬세한 위계.** 굵기 700~900 과 알약뿐이라 "약한 강조" 를 표현할 수단이 적다. 사용량 표처럼 수치가 많은 화면은 이 문법에 잘 안 맞는다(이번 세트 밖).
- **라이트 코랄의 채도.** 4.5:1 을 지키느라 #d1370f 로 어둡게 잡았다. 더 밝은 코랄(#ff7a5c)은 다크와 통화 무대에서만 쓴다.

## 10. CSS 만으로 못 한 것 (2차 세션으로)

- **홈 상단 블록의 내용**: 코랄 블록에 "오늘 할 일 하나" 같은 더 큰 문구나 최근 점수 요약을 넣고 싶지만 문구를 CSS 로 만들 수 없다. 지금은 기존 카드 제목·설명·버튼을 키운 것이다.
- **통화 시계와 링**: 링(`.timer-ring`)은 48px 로 키웠을 뿐이다. 시계 숫자 뒤에 남은 비율을 가로 막대로 두거나 링을 숫자 둘레로 두려면 Timer 마크업을 바꿔야 한다.
- **통화 상태의 위치**: 상태 알약을 시계와 같은 줄(왼쪽 시계·오른쪽 상태)에 두는 편이 "무대 상단 조명" 에 가깝지만 `.call-top` 과 `.call-main` 이 다른 부모라 `grid`/`order` 로 묶을 수 없다.
- **말풍선 화자 라벨**: 숨겨진 "나/상대" 를 알약 위 작은 라벨로 보이게 할 수 있으나(02-build-rules 의 `.sr-only` 되돌리기) 알약 안에 들어가 어색해 쓰지 않았다. 라벨을 알약 밖에 두려면 Bubble 마크업 변경이 필요하다.
- **점수 타일의 순서·크기**: 네 타일을 같은 크기 2×2 로 두었다. 가장 낮은 점수를 크게, 나머지를 작게 두는 "오늘의 과제" 배치는 데이터 기반 정렬이라 컴포넌트가 해야 한다.
- **채팅 툴바**: 체크박스·버튼·배지가 한 줄에 섞여 알약 문법에서 가장 어색한 요소다. 힌트 토글을 알약 스위치로 바꾸려면 마크업이 필요하다.
- **헤더의 모의 모드 칩**: 배지 토큰(caution)을 그대로 써서 황색 알약이다. 코랄 문법에 맞추려면 Badge 톤을 따로 줘야 한다.
- **다크 모드 `theme-color`**(주소창): 루트 레이아웃의 고정값(#f4f4f1/#131315)이라 시안 캔버스(#fff6e9/#141210)와 어긋난다.
