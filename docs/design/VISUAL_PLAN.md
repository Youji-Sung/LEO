# 시각 방향 1차 세션 계획

전제와 산출물은 `VISUAL_BRIEF.md`. 이 문서는 순서와 멈추는 지점만 정한다. 각 단계 안에서 무엇을 어떻게 할지는 세션이 정한다.

## 1. 이해

- 현재 서비스를 실제로 실행해 모든 화면을 직접 본다. 이전 세션의 산출물(`PRINCIPLES.md`, `SYSTEM.md`, `WRITING.md`, `SCREENS.md`, `screenshots/after/`)을 읽는다.
- 서비스와 사용자에 대한 세션 나름의 이해를 짧게 적는다(`docs/design/directions/00-understanding.md`). 이전 세션의 분석을 그대로 받아들일 필요는 없다.

## 2. 방향 탐색

- 서로 다른 방향을 넓게 탐색한다. 몇 개를 검토하든 자유. 탐색 과정에서 참고한 것은 출처를 적는다.
- 탐색한 방향 중 3개를 고르고, 왜 이 셋인지(왜 나머지는 아닌지) 적는다.

## 3. 시안 구현

- 세 시안을 **같은 화면 세트**로 구현한다. 구현 방식(브랜치, 테마 전환 변수 등)은 세션이 정한다.
- 세 시안은 병렬로 만들어도 된다(서브에이전트). 단, 화면 세트와 비교 형식은 먼저 정해서 세 시안이 같은 기준으로 비교되게 한다.

## 4. 정리

- 시안별 스크린샷(데스크톱·모바일 × 라이트·다크)과 한 쪽 설명을 `docs/design/directions/<시안>/`에 둔다.
- `docs/design/directions/README.md`: 비교표, 각 시안을 로컬에서 보는 방법, 세션의 추천(있으면)과 이유, 운영자가 선택을 적을 "선택" 칸(비워 둔다).

## 5. 멈춤

- 커밋하고 push한다.
- 마지막 메시지에 세 시안의 요약과 보는 방법을 적는다.
- **여기서 끝낸다.** 어느 시안도 적용하지 않고, 2차 작업을 시작하지 않는다.
